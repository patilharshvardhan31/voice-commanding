# Voice Command Shopping Assistant

## Overview
Voice Command Shopping Assistant is a shopping list manager that allows users to manage their shopping list using voice commands. The application is designed to support natural language processing, smart product suggestions, multilingual voice input, and category-based organization.

## Planned Features
- Voice-based shopping list management
- Natural language understanding
- Smart product recommendations
- Shopping history tracking
- Quantity management
- Voice search
- Category management

## Tech Stack
- React
- Spring Boot
- PostgreSQL
- Web Speech API
- OpenAI/Groq API
